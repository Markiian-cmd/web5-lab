# Лабораторна робота №2

Маркіян Задерецький, КБ-201. Національний університет «Львівська політехніка», кафедра захисту інформації, спеціальність F5 «Кібербезпека». Львів.

## Частина 1: HTML

Відкрийте `index.html` у браузері. Це самостійне резюме без CSS та JavaScript із семантичними розділами, заголовками, списками й посиланнями.

## Частина 2: React

Із кореня репозиторію виконайте:

```sh
cd lab_2_react
npm install
npm run dev
```

Відкрийте адресу, яку виведе Vite в терміналі. Для зупинки сервера натисніть Ctrl+C. У Windows PowerShell, якщо запуск `npm.ps1` заблоковано, використовуйте `npm.cmd` замість `npm`.

Використовуйте актуальну LTS-версію Node.js, сумісну з Vite. Проєкт перевіряється з Node.js 24.

```sh
npm run lint
npm run build
```

`build` створює папку `dist`, яку не потрібно додавати до Git.

### Структура

- `src/main.jsx` монтує React-застосунок у `#root`.
- `src/App.jsx` збирає сторінку з компонентів.
- `src/components/` містить `Header`, `About`, `Education`, `Experience`, `Contacts`, `Footer`.
- `src/data/cv.js` містить дані резюме, які App передає компонентам через props.
- `Experience` виводить проєкти через `map`, використовуючи стабільний `key`.

HTML- та React-версії мають однаковий зміст. Стилі стартового шаблону не підключені.

### Дерево компонентів

Запустіть `npm run dev`, відкрийте сторінку у браузері зі встановленим React Developer Tools. Натисніть F12 і відкрийте вкладку Components (за потреби в меню додаткових вкладок). Розгорніть App:

```text
App
├── Header
├── About
├── Education
├── Experience
├── Contacts
└── Footer
```

Для майбутнього звіту потрібно зробити справжній скриншот цієї вкладки. Наведена схема не замінює скриншот.
